About the project

The project I am currently working on explores how the Model Context Protocol (MCP) can be used together with large language models (LLMs) to support music score analysis. The project has an existing GitHub repository: encoding-music-mcp.

Many musicians and music researchers may not be familiar with programming or data visualisation tools, even though they often work with complex musical structures and analytical questions. This project aims to make music score analysis more accessible by allowing users to interact with music analysis tools through natural language.

By setting up an MCP server, either locally or remotely, and connecting it to a compatible MCP client such as Claude Desktop, users can ask questions about musical scores in plain language. The LLM can then call tools from the MCP server, retrieve analysis results, and help interpret them in a more user-friendly way.

My role in this project was to extend the existing MCP-based workflow by developing and testing tools that make Music Encoding Initiative (MEI) score analysis easier to generate, visualise, and interpret through natural language. I worked on Python-based MCP tools for musical analysis and visualisation, including weighted note distribution plots, melodic n-gram heatmaps, sonority n-gram progress visualisations, voice range summaries, notation rendering, notation highlighting, and audio playback of score excerpts. I also contributed to the workflow for registering MEI files that are supplied by users, so that users are not limited to the built-in score collections.

A key part of my work was connecting computational music analysis outputs to more accessible user-facing formats. Rather than returning only raw tables or code-oriented data, the tools produce structured results, visual payloads, rendered notation, and playback resources that can be displayed inside MCP-compatible clients. I also tested these tools with Claude Desktop to explore how a user could request an analysis in plain language and receive both the result and an explanation without needing to run Python code directly.

This demo illustrates how users can request music analysis results through natural language in Claude Desktop. Here, the user asks for a weighted note distribution plot for two Bach inventions, and the MCP server calls the relevant tool to generate a visualisation and interpretation. This shows how MCP can make computational music analysis more accessible to musicians and researchers without requiring them to use programming or data visualisation software directly.
