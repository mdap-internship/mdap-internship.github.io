About me

I’m Mila Pacompia, an MDAP intern in Semester 2, 2026. I like working where software engineering meets research: turning messy historical sources into clean, searchable data that researchers can actually explore. I care about well-documented, reproducible pipelines and about tools that are pleasant to use for people who aren’t developers.

The project

Migrant Music-Making and Dance in Postwar Australia is a platform for exploring the cultural lives of postwar migrants as they appear in The Good Neighbour (1950–1968), the Department of Immigration’s newspaper for “New Australians”. More than ten thousand migrants are named in its pages. The site lets researchers browse articles, search for features on music, dance and other topics, look up the people mentioned, and see visualisations of migrant journeys.

The platform is a Django web app backed by PostgreSQL (with pgvector), plus Celery and Redis for background imports, deployed with Docker.

What I did

Data cleaning

Built a cleanup pipeline that finds and fixes malformed article titles and topics. It writes a report of every record it changes so the results can be reviewed before they’re saved to the database.

Occupations model

Redesigned how people’s professions are stored. Original job titles became their own Occupation model, people can now have several occupations, and a mapper groups the titles into categories. I also wrote the data migrations and updated the visualisation of people by occupation.

People ↔ locations matching

Wrote a multi-step pipeline (match people → match locations → persist) that links people in the newspaper to the places they came from or settled in, using fuzzy name matching with a configurable threshold. It can run end-to-end or one step at a time, and it has a dry-run mode and validation.

Duplicate merging

Added tools for finding duplicate people and a merge action in the Django admin, so the research team can combine duplicate records without writing any code.

Semantic search

Built a vector index that embeds articles, people and locations with a local ONNX model (bge-small-en-v1.5) and stores the vectors in pgvector, so the site can search by meaning rather than exact words. Long articles are split into chunks, and records that haven’t changed are skipped when the index is rebuilt.

Deployment & docs

Updated the Docker setup so the pipelines can run in production, improved list pagination and how search results are displayed, and documented every pipeline with step-by-step instructions for running it locally and on the server.
